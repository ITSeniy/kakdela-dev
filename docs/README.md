## Как поддерживать документы

Команды и требования обновлять в `DEVELOPMENT.md`, состояние работ — в `CURRENT_PHASE.md`, эксплуатацию — в профильных инструкциях. README даёт ссылки на эти источники. В карточках отделять наличие кода от выполненного DoD; исторические результаты проверки всегда сопровождать датой.

Исходные audit-отчёты и архивные планы не переписывать под новое состояние: добавлять новый датированный результат и ссылку из актуального документа.
