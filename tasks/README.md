# Карточки задач

Каталог спецификаций и критериев приёмки (DoD). На 2026-09-15 — **68 карточек**. [Текущий этап](../.claude/CURRENT_PHASE.md) содержит актуальную сводку реализации и оставшихся проверок.

Карточки сохраняют исходное задание и историю выполнения. Старые модели, предполагаемые пути, технологии и галочки не определяют текущее состояние кода. Перед задачей сверить реализацию; не начинать уже существующую функцию заново и не закрывать ручной DoD по одному typecheck.

## Работа с карточкой

1. Прочесть [соглашения](../.claude/CONVENTIONS.md), [текущую архитектуру](../ARCHITECTURE.md) и текущий этап.
2. Сверить файлы в scope и критерии приёмки с кодом; старые ссылки на номера разделов относятся к [архивному плану](../docs/archive/ARCHITECTURE-2026-09-15.md).
3. Выполнить согласованную задачу, отметить проверенные критерии с датой. Оставить явно перечисленными непроверенные сценарии.
4. Новые задачи оформлять по [_template.md](_template.md), не переиспользуя существующий номер.

Пикер демонстрации назывался T-095 в прежней сводке, но отдельной карточки T-095 нет. Его реализация и ограничения отмечены в текущем этапе; пустую карточку задним числом не создаём.
