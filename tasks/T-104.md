# T-104: Голосовые сообщения (запись на мобиле, прослушивание везде)

**Phase:** 6+ — мобильный клиент (расширение cloud-DM/каналов)
**Model:** Sonnet (feature; крипто/натива не затронуты)
**Estimate:** 1 сессия + ручной прогон на эмуляторе/устройстве

## Контекст

Голосовые записываются в мобильном клиенте (и в web-режиме на узком вьюпорте) и
уходят **обычным вложением** через существующий двухфазный upload (presign →
MinIO → finalize). Никакого нового транспорта: desktop/web получают сообщение
по WS-инвалидации и рендерят компактный плеер. Секретные чаты НЕ затронуты
(там composer text-only; голосовые в E2EE = отдельная задача: шифрование
медиа + слепой релей, сервер не должен видеть файл).

Формат: `MediaRecorder` → webm/opus 32 кбит/с (Android WebView и WebView2 —
Chromium), fallback `audio/mp4`. Каверза формата: webm из MediaRecorder **не
содержит duration** в метаданных (`<audio>.duration = Infinity`), поэтому
длительность замеряется при записи и хранится в БД (`files.duration_sec`).

## Реализация (код готов)

- **ginzu** `api-types.ts`: `Attachment.voice` + `Attachment.durationSec`;
  `PresignRequest.voice/durationSec` (voice учитывается только для `audio/*`);
  `audio/webm` в `PRESIGN_ALLOWED_CONTENT_TYPES`.
- **speedy**:
  - `db/schema.ts` + миграция `0030`: `files.voice boolean`, `files.duration_sec int`.
  - `lib/file-validation.ts`: `audio/webm` разрешён; magic-bytes: file-type
    различает webm только по контейнеру (всегда `video/webm`) — заявленный
    `audio/webm` при обнаруженном `video/webm` валиден.
  - `routes/files.ts`: presign персистит `voice`/`durationSec`, `toAttachment`
    отдаёт их клиентам.
- **polly**:
  - `features/chat/useNoteRecorder.ts` — «движок» записи (MediaRecorder,
    таймер, автостоп 10 мин, отсев записей <0.5 с, глушение микрофона при
    размонтировании); `VoiceRecorder.tsx` — `VoiceRecorderBar` (отмена · пульс ·
    таймер · отправить). Хук общий с кружками (T-105, `video: true`).
  - `features/chat/Composer.tsx` — на мобиле пустой композер показывает
    микрофон вместо send; во время записи строка композера заменяется на
    VoiceRecorderBar; готовая запись грузится с `{voice, durationSec}` и
    сразу уходит сообщением.
  - `features/chat/media/VoiceMessage.tsx` — компактный плеер (play/seek/время,
    без имени файла и громкости); duration из `attachment.durationSec`, при
    `duration=Infinity` перемотка прямым `currentTime`.
  - `AttachmentView.tsx`: `kind=audio && voice` → VoiceMessage, иначе AudioPlayer.
  - `media/controls.tsx` Seekbar: mouse-события → pointer-события + `touch-none`
    (иначе перемотка не работает на таче).
  - `files/upload.ts`: `voice/durationSec` в presign; `.weba` в пикере.

Гейты: `pnpm typecheck` (все пакеты), speedy-тесты (46), web build, миграция
применена локально.

## Явно вне скоупа

- Голосовые в секретных чатах (E2EE-медиа).
- Waveform-визуализация, скорость ×1.5/×2, «слушать в фоне» — по желанию потом.
- Кнопка записи на desktop (снять гейт `isMobile` — одна строка, если захочется).
