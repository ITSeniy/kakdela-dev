# T-107: Серверные профили (per-server ник и аватар, как в Discord)

**Phase:** 5 — полировка
**Model:** Sonnet (feature)
**Estimate:** 1 сессия

## Контекст

Свой ник и аватар для каждого сервера поверх глобального профиля. На одном
сервере ты «Котлета» с гифкой, на другом — обычный профиль. DM и глобальный
профиль не затрагиваются (как в Discord).

Ключевое архитектурное решение: **сервер отдаёт эффективные значения**.
`MemberPublic.displayName`/`avatarUrl` — уже с учётом серверного профиля
(nickname ?? global), сырые override'ы едут отдельными optional-полями
`nickname`/`serverAvatarUrl`. Клиент везде резолвит авторов через
`['members', serverId]` — поэтому чат, member list, реплаи, тайлы войса и
строки ChannelList получили ники автоматически, без правок рендера.

## Реализация (код готов)

- **БД**: `server_members.nickname` + `server_members.avatar_url`
  (миграция `0032_wise_captain_britain`, применена локально).
- **ginzu**:
  - `MemberPublic`: displayName/avatarUrl — эффективные; + `nickname`,
    `serverAvatarUrl` (сырые override'ы);
  - `PatchMemberProfileRequest` / `MemberProfileResponse`;
  - WS `member.profile {serverId, userId, nickname, avatarUrl}`.
- **speedy**:
  - `GET /servers/:id/members` — коалесценция эффективных значений
    (сортировка тоже по эффективному имени);
  - `PATCH /servers/:id/members/me` — свой серверный профиль (только своё,
    null = сброс), broadcast `member.profile`;
  - `voice.ts` join серверного ГС — LiveKit-токен несёт ник;
  - `search.ts`, `inbox.ts`, `resolveReplies` (messages.ts) — LEFT JOIN
    server_members + COALESCE (в DM join пустой → глобальный профиль);
  - mention-кандидаты — `@ник` резолвится (эффективное имя кандидата).
- **polly**:
  - `App.tsx`: `member.profile` → invalidate `['members', serverId]`;
  - `servers/ServerProfileModal.tsx` — модалка: ник (placeholder =
    глобальное имя, пусто = сброс) + аватар через AvatarCropper c
    `allowGif` (T-106: gif-аватар оживает в войсе) + «как в профиле»;
  - пункт «профиль на сервере» в меню действий сервера (ChannelList).

Гейты: `pnpm typecheck` (все пакеты), speedy-тесты 46/46, миграция применена.

**Фикс после первого прогона (2026-07-05):** своя карточка в ГС брала
имя/аватар из auth store (глобальный профиль) — теперь из members
(`VoiceScreen`, memberMap для self); у чужих карточек members теперь
первичнее LiveKit-имени (то — снимок на момент джойна, протухает при смене
профиля посреди звонка).

## Явно вне скоупа (кандидаты на след. итерацию)

- Смена чужого ника админом (Discord's MANAGE_NICKNAMES).
- Серверный профиль в ProfileModal-карточке (сейчас там глобальный профиль;
  ник виден в чате/списке участников).
- Per-server баннер/about.
- Упоминания, набранные СТАРЫМ именем до смены ника, не переиндексируются —
  by design (снимок на момент отправки).
