# T-105: Кружки (видео-заметки как в Telegram)

**Phase:** 6+ — мобильный клиент (расширение cloud-DM/каналов)
**Model:** Sonnet (feature; повторяет схему T-104)
**Estimate:** 1 сессия + ручной прогон на эмуляторе/устройстве

## Контекст

Круглые видео-сообщения с фронталки, записываются в мобильном клиенте (и в
web-режиме на узком вьюпорте), просматриваются на всех клиентах. Полностью
повторяет транспорт T-104: `MediaRecorder` → обычное вложение через presign →
MinIO → finalize, флаг в БД, особый рендер. Никакого нового бэкенд-пайплайна.

Формат: webm (vp8+opus, ~1 Мбит/с видео + 32 кбит/с звук; минута ≈ 8 МБ при
лимите 25 МБ), fallback `video/mp4`. Запись капится **60 секундами** (как в
Telegram). Камера может отдать не-квадрат — обрезка до круга остаётся за
рендером (`object-fit: cover` + `border-radius: 50%`), видео НЕ перекодируется.
Валидацию менять не пришлось: `video/webm`/`video/mp4` уже в whitelist и
детектятся magic bytes напрямую.

## Реализация (код готов)

- **ginzu**: `Attachment.circle`, `PresignRequest.circle` (учитывается только
  для `video/*`; `durationSec` общий с голосовыми).
- **speedy**: `files.circle boolean` (миграция `0031`, применена локально);
  presign персистит флаг, `toAttachment` отдаёт.
- **polly**:
  - `features/chat/useNoteRecorder.ts` — общий «движок» записи (T-104+T-105):
    `video: false` = голосовое, `video: true` = кружок (фронталка 480×480
    ideal, автостоп 60 с, экспорт `stream` для превью). `VoiceRecorder.tsx`
    похудел до `VoiceRecorderBar`.
  - `features/chat/VideoNoteRecorder.tsx` — `VideoNoteOverlay`: полноэкранная
    подложка, живое круглое превью (зеркальное, сама запись не зеркалится),
    таймер, отмена/отправить.
  - `features/chat/media/VideoCircle.tsx` — круглый inline-плеер: тап =
    play/pause, SVG-кольцо прогресса вокруг круга, обратный отсчёт времени;
    duration из `attachment.durationSec` (webm без метаданных, как у голосовых).
    Перемотки нет намеренно (кружок ≤1 мин).
  - `AttachmentView.tsx`: `kind=video && circle` → VideoCircle (кружки
    исключены из лайтбокс-ленты); `Composer.tsx`: на мобиле пустой композер
    показывает две круглые кнопки — кружок (ghost) + микрофон (accent).

Гейты: `pnpm typecheck` (все пакеты), speedy-тесты (46), web build, миграция
применена.

## Явно вне скоупа

- Кружки в секретных чатах (E2EE-медиа — вместе с голосовыми).
- Перемотка по кольцу, «кружок поверх чата при скролле», переключение камер.
- Квадратное перекодирование видео (кроп на рендере достаточен для своих клиентов).
